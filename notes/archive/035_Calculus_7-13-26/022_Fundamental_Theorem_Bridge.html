Fundamental Theorem Bridge

Build the bridge shape A(x) from the wind-speed graph f(x). The rule is the Fundamental Theorem of Calculus: A′(x) = f(x).

    Key idea

    Height on top = slope on bottom.
    If f(x)>0, then A rises. If f(x)<0, then A falls. If f(x)=0, then A has a horizontal tangent.
