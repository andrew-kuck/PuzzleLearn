create an activity with html, css, and javascript: there will be an mxn grid on the screen, where m and n are javascript constants. some number b of the grid squares will have bombs in them; b is also a javascript constant. the user will have a token that starts in the lower left square and a target square (with a star in it) that is in the upper right. all of the squares in the grid are given one of c colors, at random; c is given by a javascript constant. the user is given a text editor box into which to type conditional logic code using javascript syntax. in this code, the user can reference squareColor, which is an existing variable matching the string of the color the token is currently on. the user can also reference squareColorLeft, squareColorRight, squareColorUp, squareColorDown, which references the square colors to the left, right, up, and down of the current token square, with the value being null if no such square exists (because the token is at an edge). Within the user's javascript code, they can call the function moveLeft(distance), moveRight(distance), moveUp(distance), and moveDown(distance), where distance gives the number of squares for the token to move. if the token hits an edge, it simply stops its journey early. if it hits a bomb it blows up and returns to the original starting square in the lower left. the user can only use conditional logic javascript and can only call one move function for a given condition. also, the code can only have one if: that is, one if and optionally any number of else if lines, and optionally one else. when the user clicks the Go button, the code runs automatically line by line, indicating the current line by highlighting it. if a condition is met, that code block is highlighted green, and if there is a move function in the block, the token on the grid moves according to the function. after the token moves the code executes again from the beginning, just as before but with the token in a new position. to indicate that the user's code runs as a loop, have a line above the editable code region: "while (success == false && exploded == false)". if the user blows up from a bomb, the code stops executing and the user can edit it again before hitting Go. if the user reaches the success star in the upper right, "Great Job!" appears over the screen, a progress bar is advanced, and after a slight pause a new problem is presented. after 5 successes, the progress bar is full and the function activityComplete() is called.
